تولید و مدیریت خودکار سئوی محصولات ووکامرس با کمک هوش مصنوعی، همراه با صفحه بازبینی و تایید پیش از اعمال تغییرات.

== Description ==

این افزونه برای هر محصول ووکامرس، با اتصال به ChatGPT، Claude یا هر سرویس هوش مصنوعی سازگار با OpenAI (از جمله سرویس‌های ایرانی)، پیشنهادهای سئو تولید می‌کند:

* عنوان محصول، توضیحات کوتاه و توضیحات کامل
* عنوان متا سئو، توضیحات متا سئو، کلیدواژه کانونی و کلیدواژه‌های متا (یواست)
* متن جایگزین (ALT) تصویر شاخص

هیچ‌کدام از این مقادیر بدون تایید مستقیم مدیر محتوا از صفحه «بررسی و تایید» روی محصول اعمال نمی‌شود. در آن صفحه، مقدار فعلی و پیشنهاد هوش مصنوعی برای هر فیلد کنار هم و همراه با چک‌لیست مشکلات سئوی همان فیلد نمایش داده می‌شود و با یک کلیک می‌توان هرکدام را به‌صورت مجزا پذیرفت یا رد کرد. صفحه بررسی به‌صورت اسلایدر بین محصولاتِ در صفِ بررسی حرکت می‌کند.

== نقشه راه فازها ==

= فاز ۱ (این نسخه) =
* زیرساخت: جدول پیشنهادها، تنظیمات، آداپتورهای OpenAI / Claude / سرویس عمومی سازگار با OpenAI (برای سرویس‌های ایرانی)
* موتور تولید پیشنهاد بر اساس اطلاعات واقعی محصول (بدون ادعای نادرست)
* چک‌لیست قانون‌محور سئو (طول عنوان/متا، وجود کلیدواژه کانونی، ALT تصویر شاخص و ...)
* تریگر خودکار روی انتشار محصول جدید (اختیاری، از تنظیمات)
* صفحه لیست محصولات با وضعیت سئو و تعداد ایرادها
* صفحه بررسی و تایید به‌صورت اسلایدر با مقایسه مقدار فعلی/پیشنهادی و تایید تکی هر فیلد
* تولید دسته‌ای (چند محصول هم‌زمان) با فاصله زمانی برای جلوگیری از محدودیت سرویس

= فاز ۲ (پیشنهادی) =
* کش/ذخیره چک‌لیست سئو روی هر محصول برای فیلتر و جست‌وجوی سریع‌تر در لیست
* تاریخچه کامل تغییرات هر محصول با امکان بازگردانی (revert)
* مقایسه هم‌زمان خروجی چند سرویس هوش مصنوعی برای یک محصول

= فاز ۳ (پیشنهادی) =
* داشبورد آماری (درصد پوشش سئو، هزینه/تعداد درخواست هر سرویس، محصولات پرمشکل)
* اجرای گروهی خودکار روی کل محصولات فاقد سئو با نوار پیشرفت
* اعلان ایمیلی/پیامکی هنگام آماده شدن دسته جدید برای بررسی

== Installation ==

۱. پوشه افزونه را در مسیر wp-content/plugins قرار دهید (نیاز به فعال بودن ووکامرس و Yoast SEO دارد).
۲. از بخش افزونه‌ها در پیشخوان، آن را فعال کنید.
۳. از منوی «سئوی هوشمند» → «تنظیمات»، حداقل یکی از سرویس‌های هوش مصنوعی را فعال و کلید API آن را وارد کنید.
۴. از «لیست محصولات» یا «بررسی و تایید» تولید سئو را برای محصولات شروع کنید.
