افزونه اختصاصی ورود و ثبت‌نام کاربران با کد تایید پیامکی از طریق ملی‌پیامک برای سایت آرانکیا.

== Description ==

این افزونه امکان ورود و ثبت‌نام هم‌زمان کاربران با کد تایید پیامکی (OTP) را از طریق سرویس ملی‌پیامک فراهم می‌کند و شامل امکانات زیر است:

* فعال و غیرفعال کردن کل پنل ورود پیامکی
* اتصال به ملی‌پیامک با دو روش نام کاربری/رمز عبور یا کلید API
* امکان ورود جایگزین با رمز عبور
* پشتیبانی از ریکپچای گوگل (نسخه ۲ و ۳) با تنظیم مجزا برای هر فرم
* طراحی اختصاصی و کاملا قابل تنظیم (آیکون، رنگ‌ها، متن‌ها)
* پیام‌های خطا و هشدار قابل ویرایش با مقادیر پیش‌فرض فارسی
* شورت‌کد `[arankia_sms_login]` با قابلیت سوییچ بین ورود و ثبت‌نام
* امکان جایگزینی صفحه ورود پیش‌فرض وردپرس

== Installation ==

۱. پوشه افزونه را در مسیر wp-content/plugins قرار دهید.
۲. از بخش افزونه‌ها در پیشخوان، آن را فعال کنید.
۳. از منوی «ورود پیامکی» در پیشخوان تنظیمات ملی‌پیامک و سایر بخش‌ها را تکمیل کنید.
۴. شورت‌کد `[arankia_sms_login]` به‌صورت خودکار در یک صفحه جدید قرار می‌گیرد؛ در صورت نیاز آن را در هر صفحه دیگری هم استفاده کنید.
