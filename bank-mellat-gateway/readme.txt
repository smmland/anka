اتصال امن درگاه پرداخت بانک ملت (به‌پرداخت ملت) به ووکامرس.

== Description ==

این افزونه یک روش پرداخت جدید با عنوان «بانک ملت» به صفحه تسویه‌حساب ووکامرس اضافه می‌کند و با استفاده از وب‌سرویس رسمی SOAP به‌پرداخت ملت (Behpardakht Mellat) کار می‌کند.

ویژگی‌ها:

* تنظیمات کامل از داخل مسیر ووکامرس ← تنظیمات ← پرداخت‌ها ← بانک ملت
* دریافت ترمینال آی‌دی، نام کاربری و رمز عبور وب‌سرویس
* پیاده‌سازی کامل چرخه تراکنش: PayRequest، Verify، Settle و Reversal خودکار در صورت خطا
* جلوگیری از پردازش تکراری سفارش با بررسی وضعیت پرداخت و اعتبارسنجی RefId
* پشتیبانی از HPOS (ذخیره‌سازی سفارش‌های ووکامرس)
* گزینه تبدیل خودکار واحد پول تومان به ریال برای ارسال به بانک
* پیام‌های خطای فارسی بر اساس کدهای بازگشتی بانک
* ثبت رویداد اختیاری در لاگ ووکامرس برای عیب‌یابی (بدون ثبت رمز عبور)

== Installation ==

۱. پوشه `bank-mellat-gateway` را در مسیر `wp-content/plugins` قرار دهید.
۲. از بخش افزونه‌ها در پیشخوان وردپرس آن را فعال کنید (نیازمند ووکامرس فعال و اکستنشن PHP SOAP).
۳. به مسیر ووکامرس ← تنظیمات ← پرداخت‌ها ← بانک ملت بروید.
۴. ترمینال آی‌دی، نام کاربری و رمز عبور دریافتی از بانک ملت را وارد و ذخیره کنید.
۵. گزینه «فعال‌سازی» را تیک بزنید.
